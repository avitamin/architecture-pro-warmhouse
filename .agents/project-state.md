## Требования задания и открытые решения

Корневой README требует анализ монолита, выделение доменов и контекстов, диаграммы C4 и ER, выбор и документирование API, завершение контейнерного окружения и разработку MVP микросервисов.

Для задания с окружением требуется реализовать `temperature-api` с портом по умолчанию 8081, добавить настройки PostgreSQL и подключить SQL инициализации. Для MVP требуется создать сервисы телеметрии и устройств на разных ООП-языках и интегрировать их с монолитом; брокер сообщений указан как необязательный.

Границы сервисов, технологии новых компонентов, контракты взаимодействия и способ интеграции в рассмотренных документах ещё не зафиксированы как согласованные решения. Их следует обсуждать с пользователем по учебному формату из AGENTS.md. Требования README не означают, что эти компоненты уже реализованы.

## Известные ограничения

- Compose содержит незаполненные секции PostgreSQL и `temperature-api`. Для PostgreSQL не настроены требуемый приложением healthcheck, подключение скрипта инициализации и остальные параметры окружения.
- Монолит уже обращается к внешнему API температуры, но отсутствующий сервис не позволяет считать интеграцию готовой.
- Команды запуска в README приложения описывают ожидаемый сценарий; его работоспособность не подтверждена. Команды Go необходимо выполнять из каталога модуля, а не из корня репозитория.
- Автоматические тесты пока отсутствуют; успешную компиляцию нельзя считать проверкой поведения API.
